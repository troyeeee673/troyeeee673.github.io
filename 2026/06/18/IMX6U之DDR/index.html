IMX6U之DDR

发表于 2026-06-18 分类于 Linux裸机驱动开发

IMX6U DDR

1、存储器对比

RAM和ROM

  • RAM:随机存储器，包括 SRAM（静态RAM）、DRAM（动态RAM，如SDRAM、DDR）、PSRAM（伪静态RAM） 等，掉电丢失。
  • ROM:只读存储器（但事实上也能写，如对Flash就可以进行擦除写入），包括 掩膜ROM、PROM、EPROM、EEPROM、NOR Flash、NAND Flash、eMMC、UFS 等，掉电不丢失。

SRAM：静态随机存储器

框图：

有19条地址线和16条数据线（分为高八位和低八位）以及若干控制线（通常包括片选CS#、读使能OE#、写使能WE#、字节使能UB#/LB#）。
SRAM特点就是价格贵，容量小，速度快（如PC中的三级cache用的就是sram，因为这样才能跟上CPU的速度，以及SOC内部RAM）
原理：每个存储单元由6个MOS管（6T结构）构成双稳态触发器，只要有电就能保持数据，不需要刷新电路。

SDRAM：同步动态存储器（需要刷新）

定义：SDRAM全称Synchronous Dynamic RAM，属于DRAM的一种，所有信号都与系统时钟同步。
存储原理：1个晶体管+1个电容（1T1C），电容充电代表1，放电代表0。电容会漏电，因此必须周期性刷新（一般64ms内完成一次全部刷新）。
特点：

  • 容量比SRAM大，价格更低
  • 需要专用内存控制器管理刷新和时序
  • 地址线分时复用（行地址+列地址），节省引脚
  • 读/写需要先激活行（RAS），再发列选通（CAS）

DDR

DDR全称Double Data Rate SDRAM（双倍数据率同步动态随机存储器），在时钟的上升沿和下降沿都传输数据，数据率是时钟频率的两倍。
发展历史：DDR → DDR2 → DDR3 → DDR4 → DDR5（IMX6U支持DDR3/DDR3L和LPDDR2）

DDR1

  • 工作电压：2.5V
  • 预取位数：2-bit（2n预取）
  • 数据速率：200~400 MT/s（DDR-200 至 DDR-400）
  • 封装：TSOP-66或FBGA
  • 特点：第一代DDR，信号走线常用T型拓扑

DDR2

  • 工作电压：1.8V
  • 预取位数：4-bit（4n预取）
  • 数据速率：400~800 MT/s（DDR2-400 至 DDR2-800）
  • 封装：FBGA（240pin DIMM，防呆槽位置与DDR3不同）
  • 特点：
    • 引入片上终结电阻（ODT），减少信号反射
    • 同频下内部核心频率只有DDR1的一半，功耗更低

DDR3

  • 工作电压：1.5V（DDR3L为1.35V）
  • 预取位数：8-bit（8n预取）
  • 数据速率：800~2133 MT/s（DDR3-800 至 DDR3-2133）
  • 封装：FBGA（240pin DIMM，防呆槽与DDR2位置不同）
  • 特点：
    • 引入Fly-by菊花链拓扑，地址/命令/时钟线串联各颗粒
    • 需要**Write Leveling（写均衡）**训练，补偿各颗粒时钟延时差异
    • 引入RESET#引脚，增强功耗管理
    • 支持自刷新温度补偿（SRT）和自动自刷新（ASR）
  1. 重要时间参数
    • 传输速率：DDR3 1600、DDR3 1866、DDR4 2400、DDR4 3200 MT/s，表示每秒多少兆次数据传输（MT/s = Mega Transfers per second）。IMX6U的MMDC最高支持800MT/s（400MHz时钟）。
    • tRCD：行寻址到列寻址的延时（RAS to CAS Delay）。从发出行激活命令到可以发出列读写命令的最小时间间隔。例如DDR3-1600典型值为13.75ns。
    • CL参数：列地址选通潜伏期（CAS Latency）。发出列读命令后，数据在DQ线上出现的时钟周期数。CL值越小，读延迟越低。
    • tRC：tRC是两个ACTIVE命令，或者ACTIVE命令到REFRESH命令之间的周期，tRC = tRAS + tRP，表示同一Bank内完成一次完整行操作的最小周期。DDR3L数据手册会给出这个值，比如NT5CC256M16EP-EK的tRC值为47.91ns。
    • tRAS：tRAS是ACTIVE命令到PRECHARGE命令之间的最小时间，即行激活后必须保持的最短时间，之后才能对该行进行预充电。DDR3L的数据手册同样也会给出此参数，NT5CC256M16EP-EK的tRAS值为34ns。

MX6U MMDC多模控制器

  1. 多模支持DDR3/DDR3L LPDDR2 x16位
  2. MMDC最高支持DDR3频率是400MHz，800MT/S
  3. MMDC提供的DDR3连接信号。6ULL给DDR提供了专用的IO

DDR 时钟配置

DDR 使用的时钟源为 MMDC_CLK_ROOT=PLL2_PFD2=396MHz。
配置步骤：

  • 步骤1：CBCMR 寄存器的 PRE_PERIPH2_CLK_SE 位来选择，也就是 bit22:21，设置 pre_periph2 时钟源，设置为 01，也就是 PLL2_PFD2 作为 pre_periph2 时钟源。
  • 步骤2：CBCDR 寄存器的 PERIPH2_CLK_SEL 位，也就是 bit26，设置为 0，PLL2 作为 MMDC 时钟源，396MHz。
  • 步骤3：CBCDR 寄存器的 FABRIC_MMDC_PODF 位，bit5:3，设置 0，也就是 1 分频。最终 MMDC_CLK_ROOT=396MHz。

补充说明：PLL2是系统PLL，主频528MHz，其PFD2分频输出396MHz。396MHz经过MMDC内部倍频后，DDR双沿传输等效800MT/s数据率。

DDR3L初始化与测试

  1. ddr_stress_tester 配置文件
    excel配置文件，excel配置好以后realview.inc会同步的更新。

    说明：Excel文件中填写DDR颗粒参数（如tRCD、tRP、tRFC、CL、速度等级、位宽等），工具自动生成对应的MMDC寄存器初始化脚本（.inc文件）。

  2. .inc文件
    ddr_stress_tester工具需要用到.inc文件。

    说明：.inc文件实质是一系列MMDC寄存器地址和对应值的列表，ddr_stress_tester工具通过USB串行下载模式逐条写入MMDC，完成DDR控制器的初始化配置。

  3. 测试
    ddr_stress_tester通过USB口将.inc中的配置信息下载到开发板里面。直接进行超频测试的话测试失败。

    原因分析：超频（如将400MHz时钟提升到更高频率）超出了DDR颗粒和PCB设计的额定范围。如果PCB走线过长、阻抗不匹配或颗粒本身不支持高速率，会导致信号完整性问题（眼图闭合、时序违例），测试必然失败。

  4. 做校准

    校准目的：由于PCB走线长度差异、信号反射、阻抗不连续等因素，各数据字节通道的延时不一致。校准通过逐级调整延时链，找到最佳的DQS/DQ采样点，确保读写时序正确。

最终输出：
Write leveling calibration
MMDC_MPWLDECTRL0 ch0 (0x021b080c) = 0x00000000
MMDC_MPWLDECTRL1 ch0 (0x021b0810) = 0x00070007

Write Leveling校准：针对DDR3的Fly-by拓扑，调整DQS输出延时，使各DDR颗粒在正确的时钟边沿采样到写数据。MMDC_MPWLDECTRL0/1存储各字节通道的延时值，0x00070007表示两个通道都有7级延时。

Read DQS Gating calibration
MPDGCTRL0 PHY0 (0x021b083c) = 0x01380138
MPDGCTRL1 PHY0 (0x021b0840) = 0x00000000

Read DQS Gating校准：确定DQS选通窗口的开启/关闭时机，保证控制器在有效DQS边沿范围内锁存读数据。0x01380138表示窗口开启和关闭的延时位置。

Read calibration
MPRDDLCTL PHY0 (0x021b0848) = 0x40402E32

Read校准：调整每根DQ数据线相对于DQS的采样延时，消除PCB走线不等长带来的偏斜（skew）。0x40402E32中，高16位和低16位分别对应不同字节通道的延时值。

Write calibration
MPWRDLCTL PHY0 (0x021b0850) = 0x40403432

Write校准：调整控制器输出DQ数据相对于DQS的驱动延时，确保写数据以正确的时序到达DDR颗粒。0x40403432同样包含不同字节通道的延时补偿值。

使用方式：将校准获得的寄存器值填入最终的固件初始化代码（如u-boot的DDR配置数组），量产时直接写入对应MMDC寄存器，无需每次开机重新校准。
