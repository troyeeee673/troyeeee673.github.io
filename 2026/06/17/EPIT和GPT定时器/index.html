EPIT 和 GPT 定时器

定时器是裸机驱动中非常常用的外设：既可以产生周期性中断，也可以用于按键消抖、延时和时间基准维护。i.MX6ULL 中常用的硬件定时器包括 EPIT 和 GPT。本文围绕这两个定时器的基本原理和寄存器配置展开。

1. EPIT：增强型周期定时器

1.1 EPIT 简介

EPIT（Enhanced Periodic Interrupt Timer）是增强型周期中断定时器，适合用于周期性定时任务。

EPIT 的主要特点如下：

  • EPIT 是一个 32 位向下计数器。
  • EPIT 支持多个时钟源：
    • ipg_clk = 66 MHz，本文示例选择该时钟源。
    • ipg_clk_32k。
    • ipg_clk_highfreq。
  • EPIT 可以对输入时钟进行分频。分频器为 12 位，寄存器可配置范围为 0~4095，对应实际 1~4096 分频。
  • 定时器启动后，计数寄存器的值会随时钟递减。当计数值与比较寄存器的值相等时，会触发比较中断。

EPIT 支持两种典型工作模式：

  • set-and-forget：计数器从加载值开始向下计数，计数到 0 后可重新装载，适合周期性中断场景。
  • free-running：计数器持续运行，适合需要连续时间基准的场景。

2. i.MX6ULL EPIT 实战原理

i.MX6ULL 内部有两个 EPIT 定时器，EPIT_CR 寄存器用于完成 EPIT 的核心配置。

2.1 EPIT 寄存器配置

EPIT_CR 是 EPIT 的控制寄存器，常用配置位如下：

  • bit0：EPIT 使能位。置 1 后启动 EPIT。
  • bit1：设置计数器初始值来源。置 1 后，计数器初始值来自加载寄存器 EPIT_LR。
  • bit2：比较中断使能位。置 1 后允许比较中断。
  • bit3：工作模式选择位。置 1 后工作在 set-and-forget 模式。
  • bit15~bit4：分频值配置位。
  • bit25~bit24：时钟源选择位。示例中设置为 1，表示 EPIT 时钟源为 ipg_clk = 66 MHz。

EPIT_SR 是状态寄存器，只有 bit0 有效：

  • OCIF = 1：表示比较中断已经发生。
  • OCIF = 0：表示比较中断未发生。
  • 该位采用写 1 清零机制。定时器中断处理完成后，必须及时清除中断标志位。

EPIT_LR 是加载寄存器，用于设置计数器的加载值。计数器计时到 0 后，会读取 EPIT_LR 的值并重新开始计数。

EPIT_CMPR 是比较寄存器。当计数器当前值与 EPIT_CMPR 相等时，会产生比较中断。

一个常见应用是使用 EPIT 实现 500 ms 周期定时器，并在 EPIT 中断服务函数中翻转 LED 状态，从而实现 LED 周期亮灭。

2.2 使用 EPIT 进行按键消抖

机械按键按下或释放时，电平通常不会立刻稳定，而是会产生一段时间的抖动。按键消抖的常见做法是：按键中断只负责启动一个短周期定时器，真正的按键状态判断放到定时器中断中完成。

典型流程如下：

  • 按键按下后，进入 GPIO 中断服务函数。
  • 在 GPIO 中断中启动 EPIT 定时器，定时周期设置为 10 ms。
  • 抖动期间可能多次触发中断，但只有最后一次稳定后的定时周期会完整执行。
  • EPIT 定时中断到来后，再读取按键状态并执行具体业务，例如控制蜂鸣器开关。

这样可以避免在 GPIO 中断中直接处理抖动信号，使按键逻辑更稳定，也更容易维护。

3. GPT：通用定时器

3.1 GPT 时钟源

GPT（General Purpose Timer）是通用定时器。相比简单的软件空循环延时，硬件定时器的精度更高，也不会因为 CPU 主频调整而轻易失准。

以前的延时函数常用空指令循环实现，这种方式依赖 CPU 执行速度。当 i.MX6ULL 主频发生变化后，空循环延时就不再可靠。因此，在 6ULL 中可以使用 GPT 这类硬件定时器实现更稳定的高精度延时，类似 STM32 中常用 SysTick 实现系统节拍或延时。

3.2 GPT 定时器简介

GPT 的主要特点如下：

  • GPT 是 32 位向上计数器。
  • GPT 支持输入捕获功能。
  • GPT 支持输出比较和比较中断功能。
  • GPT 有一个 12 位分频器。
  • GPT 时钟源可选，本文示例使用 ipg_clk = 66 MHz 作为 GPT 时钟源。
  • GPT 有两路输入捕获和三路输出比较。

GPT 有两种常用工作模式：

  • restart 模式：当计数值与输出比较寄存器 OCR 的值相等时，定时器会重新从 0 开始计数。需要注意，只有输出比较通道 1 支持该自动重启能力。
  • free-run 模式：计数器从 0 开始向上计数，一直计数到 0xFFFFFFFF 后溢出，再重新从 0 开始。三个输出比较通道都可以在该模式下使用。

3.3 GPT 寄存器配置

GPT_CR 是 GPT 控制寄存器，常用配置位如下：

  • bit0：GPT 使能位。为 0 时关闭 GPT，为 1 时使能 GPT。
  • bit1：计数器初始值控制位。为 0 时，计数器保留上次关闭时的值；为 1 时，计数器从 0 开始。
  • bit8~bit6：时钟源选择位。设置为 1 时，表示 GPT 时钟源为 ipg_clk = 66 MHz。
  • bit9：工作模式选择位。为 0 时工作在 restart 模式，为 1 时工作在 free-run 模式。
  • bit15：软件复位位。

GPT 的分频值不在 GPT_CR 中配置，而是在 GPT_PR 寄存器中配置。GPT_PR 的 bit11~bit0 为分频值，可设置 0~4095，对应实际 1~4096 分频。

GPT_SR 是 GPT 状态寄存器，常用标志位如下：

  • bit5：溢出标志位。
  • bit4：输入捕获通道 2 中断标志位。
  • bit3：输入捕获通道 1 中断标志位。
  • bit2~bit0：输出比较中断标志位，也就是 OF3~OF1。
