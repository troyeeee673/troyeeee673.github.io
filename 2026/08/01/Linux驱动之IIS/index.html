一、音频基础知识

1.1 为什么要音频编解码芯片（Codec）

处理器（如 i.MX6ULL）只能理解数字信号（0和1），而自然界的声音是模拟信号（连续变化的声波）。因此，需要完成两个方向的转换：

  • 录音（ADC）：麦克风采集的模拟信号 → 数字信号，处理器才能“听到”。
  • 放音（DAC）：处理器输出的数字信号 → 模拟信号，喇叭/耳机才能“发出”声音。

此外，Codec 芯片还集成了：

  • 混音器（Mixer）：控制音频通路（如将 MIC 信号直接送到耳机输出）。
  • 音量控制：通过 I2C 接口调节增益。
  • 音效处理：如 3D 环绕、EQ 均衡器等。
  • 多路输入/输出：支持多个麦克风、线路输入、耳机、喇叭等。

因此，WM8960 这类芯片不仅是 ADC/DAC，更是完整的音频处理单元。

1.2 音频文件处理过程

  • 录音方向：模拟 → 数字，通过 I2S 接口传输到 CPU。
  • 放音方向：数字 → 模拟，通过 I2S 接口从 CPU 发出。

注：I2S 是传输音频数据的协议，而 I2C 是用于配置 Codec 寄存器的控制协议，两者分工不同。

1.3 音频相关术语

术语 说明
采样率（Sample Rate） 每秒采集声音信号的次数，单位 Hz。常见：8kHz、44.1kHz（CD）、48kHz。采样率越高，声音还原越精细。
位宽（Bit Width） 每个采样点用多少 bit 表示。常见：16bit、24bit、32bit。位宽越大，动态范围越大，音质越好。
声道数（Channels） 单声道（Mono）、立体声（Stereo，2声道）、多声道（5.1、7.1等）。
数据格式（Data Format） I2S、左对齐（Left-justified）、右对齐（Right-justified）、DSP 模式等。决定了数据在 BCLK 下的排列方式。

二、I2S 音频接口

I2S（Inter-IC Sound）是飞利浦制定的数字音频传输标准，用于 CPU 与 Codec 之间传输音频数据。

WM8960 与 i.MX6ULL 通过 I2S 接口连接，主要引脚如下：

引脚 全称 功能说明
BCLK Bit Clock 位时钟，频率 = 采样率 × 位宽 × 声道数。用于数据同步。
DACLRC / ADCLRC Frame Clock（LRCK） 帧时钟，用于切换左右声道数据，频率 = 采样率。
DACDAT DAC Data In 主控 → Codec，传输要播放的数字音频数据。
ADCDAT ADC Data Out Codec → 主控，传输采集到的音频数据。
MCLK Master Clock 主时钟，由 CPU 提供，频率通常为采样率的 256 或 384 倍，用于 Codec 内部工作时钟。

注：WM8960 支持将 ADCLRC 和 DACLRC 共用，通过寄存器配置为单帧时钟模式，简化硬件连接。

三、音频传输协议对比

除了 I2S，音频传输还有以下常见协议：

协议 特点
I2S 最常用，数据在 BCLK 下降沿变化，在上升沿采样，MSB 先传，左声道在前。
左对齐（Left-justified） 数据在 BCLK 上升沿变化，MSB 在 LRCK 跳变后第一个 BCLK 周期开始。
右对齐（Right-justified） 数据的 LSB 对齐到 BCLK 周期的末尾，与 I2S 时序相反。
DSP 模式 取消 LRCK 的 50% 占空比，通过帧同步信号（FSYNC）标识数据帧起始。
AC97 支持音频 + 控制数据混合传输，带固定的帧结构，现已较少使用。
PCM（脉冲编码调制） 广义上指数字音频编码方式；在接口层面，常用于语音通信，支持多时隙（Time Slot）传输。

四、Linux 音频驱动架构：ALSA 与 ASoC

4.1 ALSA（Advanced Linux Sound Architecture）

Linux 内核原生音频框架，提供：

  • 统一的 API（用户空间使用 /dev/snd/*，如 alsa-lib）。
  • 支持多种音频设备（声卡、MIDI、混音器等）。
  • 内核驱动模型，支持 PCM、控制接口等。

4.2 ASoC（ALSA System on Chip）

ASoC 是 ALSA 在嵌入式 SoC 平台上的扩展，专门针对 ARM、MIPS 等嵌入式处理器优化。

它把音频驱动解耦为三部分：

组成部分 作用 示例 谁提供
Platform（平台驱动） 管理 SoC 端的音频接口外设（如 i.MX6ULL 的 SAI、I2S、PCM 控制器），负责 DMA 搬运、时钟控制等硬件操作。 fsl_sai.c 半导体厂商（NXP）
Codec（编解码驱动） 管理音频编解码芯片的功能，通过 I2C/SPI 配置寄存器，如音量、通路、采样率等。 wm8960.c Codec 厂商（Cirrus Logic/Wolfson）
Machine（板级驱动） 将 Platform 和 Codec 绑定在一起，描述具体的硬件连接（如 SAI2 接 WM8960，MCLK 来自哪个时钟源），注册为一个完整的声卡设备。 imx-wm8960.c 开发板厂商或开发者

4.3 三者关系总结

类比理解：

  • Platform = 邮局（提供运输渠道）
  • Codec = 信件内容（处理具体信息）
  • Machine = 地址标签（把“谁”和“怎么寄”绑定起来）
